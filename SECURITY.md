# Security Policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue: open this repository's **Security** tab and
choose **Report a vulnerability** (<https://github.com/OtohaTouka/ToukaDev/security/advisories/new>).

Useful reports include problems in the guard and cleanup scripts (`scripts/`, `dev-workflow/assets/progress/`),
in templates that project-init copies into new projects, or in procedures that could lead an AI agent to delete
data, leak secrets or skip an approval. Reports are handled on a best-effort basis; there is no fixed response time.

## Supported versions

Only the latest commit on `main` is supported.

## 回報安全問題（中文）

請不要開公開 issue；到本 repo 的 **Security** 分頁按 **Report a vulnerability**（網址同上），用 GitHub 的私下回報。
特別歡迎：守衛與清理程式、project-init 會複製到新專案的範本、可能讓 AI 代理刪資料、洩漏金鑰或跳過核准的流程漏洞。
沒有固定的回覆時間。只支援 `main` 的最新版。
