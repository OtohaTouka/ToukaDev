### 各類型預設推薦棧（AI 參考用）

| 專案類型 | 首選推薦 | 選擇原因 |
|---------|---------|---------|
| Web API | FastAPI + PostgreSQL + pytest | 文件自動生成、型別安全、新手錯誤最少 |
| 有介面 Web App（純前端） | React + TypeScript + Vitest | 最多學習資源、AI 支援最好 |
| 有介面 Web App（全端） | FastAPI（後端）+ React（前端）+ PostgreSQL | 前後端分離，分別用 Python / JS |
| 聊天機器人 / Bot | FastAPI + webhook + pytest | 平台 SDK 最成熟，部署最簡單 |
| 資料分析 / 爬蟲 | Python 腳本 + pytest（不用框架） | 輕量，不需要 Web 框架 |
| 命令列工具 | Python + Click + pytest | Click 讓 CLI 介面最容易寫 |
| 全端應用 | FastAPI + React + PostgreSQL | 分層清楚，測試好寫 |
