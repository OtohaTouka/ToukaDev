# project-init 新手導覽

> 從 SKILL.md 移入。標準模式下 AI 於流程開始時讀取本檔，向使用者說明；精簡輸出模式跳過。

## 這個 Skill 在做什麼？

在你寫第一行程式碼之前，先把「你想做什麼」講清楚，並幫你建好所有必要的基礎設施。
這就像蓋房子前先畫設計圖、打好地基——雖然看起來慢，但之後每一步都會更順。

精簡輸出模式只縮短說明；小型專案初始化則是省略 CI/CD 與 MkDocs 的初始化設定，兩者互不替代。

**你需要做什麼：**
- 回答 AI 的問題（你想做什麼功能？給誰用？）
- 選一個技術棧方案（AI 會用白話解釋每個選項）
- 確認最終的專案規格文件

**AI 會自動做什麼：**
- 建立所有目錄結構與文件骨架
- 設定測試、靜態檢查、CI/CD 工具
- 寫好第一個 git commit

**完成後的樣子：** 一個可以直接開始寫功能的空白專案，所有工具都已就位。

**看到看不懂的詞？** 查閱 [術語表](../assets/templates/glossary.md)（初始化完成後也會複製到專案的 `docs/glossary.md`）。
