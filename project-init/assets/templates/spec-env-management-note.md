## 環境設定檔管理

本專案使用以下設定方式（`.env` 系列檔案均不提交到 git）：

| 情境 | 做法 |
|------|------|
| 本機開發 | 從 `.env.example` 複製為 `.env`，填入自己的設定值 |
| CI/CD 自動測試 | 在 GitHub Actions / GitLab CI 的「Secrets」設定介面輸入 |
| 正式部署 | 在部署平台（Render、Railway 等）的環境變數設定介面輸入 |

⚠️ **正式環境的 API 金鑰和密碼，絕對不要存在任何檔案裡。**
請在部署平台的設定介面直接輸入，不要建立 `.env.production` 檔案。
