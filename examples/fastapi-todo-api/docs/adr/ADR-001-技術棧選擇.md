# ADR-001：技術棧選擇

- **日期：** 2026-05-17
- **狀態：** 已接受

## 問題
需要為這個 Todo API 範例選擇技術棧，同時兼顧「對新手友善」和「展示 ToukaDev 框架能力」兩個目標。

## 決策
選擇 **FastAPI + SQLAlchemy + SQLite（開發）**。

| 層次 | 選擇 | 理由 |
|------|------|------|
| 語言 | Python 3.11 | 最多 AI 輔助資源、語法最接近自然語言 |
| 框架 | FastAPI | 自動產生 OpenAPI 文件、型別安全、效能好 |
| ORM | SQLAlchemy 2.0 | Python 生態最成熟的 ORM |
| 資料庫（開發） | SQLite | 零設定、不需 Docker、適合入門展示 |
| 測試 | pytest + httpx | 最主流的 Python 測試組合 |
| 套件管理 | uv | 比 pip 快、現代化 |

## 為何不選其他選項
- **Django：** 功能較重，對這個小型 API 過度工程化；自動 admin 對範例用途沒有必要
- **Flask：** 需要更多手動配置（沒有內建 async、沒有自動 OpenAPI）
- **SQLite（正式）：** 不支援並發寫入；正式部署應換用 PostgreSQL（修改 `DATABASE_URL` 即可）

## 影響
- **正面：** 新手可以立刻執行，不需要先安裝 PostgreSQL 或 Docker
- **權衡：** SQLite 不適合正式多用戶環境；文件中已說明切換方式
