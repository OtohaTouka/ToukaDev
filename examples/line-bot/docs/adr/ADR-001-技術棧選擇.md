# ADR-001：技術棧選擇

- **日期：** 2026-05-17
- **狀態：** 已接受

## 問題
為 LINE Bot 選擇技術棧，兼顧「對新手友善」和「可測試性」。

## 決策
選擇 **FastAPI + line-bot-sdk v3**。

| 層次 | 選擇 | 理由 |
|------|------|------|
| 語言 | Python 3.11 | 最多 AI 輔助資源 |
| Web 框架 | FastAPI | async 支援、自動型別驗證 |
| LINE SDK | line-bot-sdk v3 | 官方 Python SDK，有型別標注 |
| 測試 | pytest + unittest.mock | 標準組合，無需額外依賴 |

## 架構決策：業務邏輯與 SDK 呼叫分離

採用「適配器模式」分離業務邏輯與 SDK 呼叫：
- `src/handlers/` — 純函式，不依賴 LINE SDK（單元測試友善）
- `src/line_client.py` — LINE API 呼叫集中點（整合測試時 mock 此層）
- `src/main.py` — FastAPI 路由 + 事件分派

## 影響
- **正面：** 業務邏輯可以用純 Python 單元測試，不需要 LINE 帳號
- **正面：** 日後若換 LINE SDK 版本，只需修改 line_client.py
- **權衡：** 增加一個模組層級，但換來更好的可測試性
