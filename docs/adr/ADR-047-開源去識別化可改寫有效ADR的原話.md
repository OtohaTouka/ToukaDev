# ADR-047：開源去識別化可改寫有效 ADR 的原話

- 日期：2026-10-22
- 狀態：已接受（ToukaDev 開源計畫由人類核准；本項是放寬，由人類單獨核准；主代理代審）
- 修訂：ADR-033 D6 與 ADR-044 D1（既有 ADR 內文不改寫；整份被取代的才可換成存根）：為了這次開源，仍有效或部分被推翻的
  ADR 也可以改寫人類原話、選項代號與個人描述
- 影響範圍：`docs/adr/` 的 ADR-034、035、036、037、039、040、041、045 共 8 份；ADR 索引；HANDOVER 的入口與說明。規則、Skill、守衛與測試都沒動

## 背景

ToukaDev 要從私人 repo 改成公開。公開 repo 只放一份整理好的最新版，私人 repo 改名保留完整歷史。開源前審查發現，最新版的
檔案裡沒有金鑰、信箱或本機路徑，但 8 份 ADR 逐字引用了人類在對話中的話：引用區塊 6 段、行內約 9 處、選項代號約 5 處，
其中一段含個人細節；另有約 20 行用「Owner」稱呼人類，以及幾處描述人類個人習慣、計畫或工具狀態的句子。

ADR-033 D6 規定既有 ADR 的內文不改寫，ADR-044 D1 只放寬到「整份被取代的 ADR 可以換成存根」。這 8 份都仍有效或只部分被推翻，
照現行規則不能改。ADR-046 D10 已規定版控文件記決定內容、不寫原話，但它只管之後新寫的文件。

## 決定

1. **D1 開源去識別化的例外**：為了把 repo 公開，可以改寫仍有效或部分被推翻的 ADR 裡的人類原話、選項代號與個人描述，
   改成決定的內容。限制：
   - 只改寫法，不改決定、理由、範圍或結論；日期、ADR 引用、「決定 N」與 D 編號、X1／X2、G1～G5 這類 ADR 自己的編號照留，
     讓其他文件的引用不斷。
   - 描述人的「Owner」改成「人類」；描述人類個人習慣或計畫的句子改成和流程有關的一般說法。
   - 原文留在私人歷史存檔，不在公開 repo 裡引用或摘錄。
   - 例外只限這次開源（下方落點表的 8 份，含之後發現的同類殘留）；其他改寫另經人類單獨核准。
2. **D2 以後的 ADR**：照 ADR-046 D10，一開始就寫決定內容、不寫原話或選項代號（人類同意的除外），不需要再用這個例外。

## 落點

| ADR | 改了什麼 |
|---|---|
| ADR-034 | 目標那句改成直述；描述人類工作方式、過去做法與偏好的三句改成一般說法 |
| ADR-035 | 背景的 3 段引用改寫成人類提出的需求（網頁、只在本機、暫存清理）；「Owner」改成「人類」 |
| ADR-036 | 背景的 2 段引用與 3 處行內原話改寫成需求與目標；描述人類讀不讀程式碼的句子改成一般說法；「Owner」改成「人類」 |
| ADR-037 | 核准原話改成「人類逐條核准了四項，也同意執行方式與 Git 範圍」 |
| ADR-039 | 一處選擇原話改成核准的做法 |
| ADR-040 | 狀態行、D5 與行數表的選項代號改成核准的內容或拿掉 |
| ADR-041 | 狀態行、D13、P-B 說明與鬆緊表的選項代號改成項目編號或內容 |
| ADR-045 | 啟動語、範圍與兩處放寬核准的原話改成決定內容；個人計畫改成一般說法；拿掉一句個人工具狀態 |

## 規則鬆緊

- 放寬：ADR-033 D6（經 ADR-044 D1）多一個可以改寫有效 ADR 內文的例外。源頭：ADR-033 D6 在刪除舊交班、證據與提案資料夾時，
  規定既有 ADR 內文不改寫，指向已刪檔案的連結以 git 歷史為準；ADR-044 D1 第一次放寬，限整份被取代的 ADR。由人類單獨核准。
- 限制與 ADR-044 相同：不改決定本身，編號與引用不斷，原文可從私人歷史取得（外部讀者看不到）。

## 後果

- 公開 repo 的 ADR 不含人類原話與個人細節；決定與理由都還在。
- 外部讀者看不到原話的上下文，只能看到改寫後的需求與決定；需要原文時，由維護者從私人歷史查。
- 本 ADR（含）以前的 ADR 裡的 commit 編號、PR 編號仍指私人歷史，ADR 索引加了一句說明。
