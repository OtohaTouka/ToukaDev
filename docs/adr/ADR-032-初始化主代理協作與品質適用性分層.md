# ADR-032：初始化主代理協作與品質適用性分層

- 日期：2026-09-14
- 狀態：DEV-A 人類核准；source 實作及測試通過；行為試行等待具體傳送同意，主代理 DEV-B 尚待完成
- 後續修訂：ADR-039 把 implementation.md 品質分層鎖定句的 docs 條件改為「只在有 `mkdocs.yml` 時執行」，
  「不得省略已宣告的 ssot、security validators」不變；quick schema v1 隨文件快速路徑 JSON 宣告一起退役
- 方案：[已核准實作計畫](../proposal/ToukaDev_Skill_初始化自主協作與跨語言品質分層實作計畫.md)

## 問題

初始化已有 INIT-A 技術棧及 INIT-B 規格的人類 gate，但缺少兩關通過後的一次委託、主代理
派工與退修流程。Debug 固定返回 dev 會使初始化中任務跳錯流程；前期尚無測試或守衛時，
也容易把尚待建立當成永久豁免。共通規則混合 Python 與 React 寫法，使其他語言難以判定義務。

## 決策

延續 ADR-031 的 SUPERVISOR_DELEGATED，不增加審核模式。INIT-A／INIT-B 仍由人類確認；
兩關通過且原始委託明確涵蓋時，主代理管理 greenfield 步驟 6–12 的執行計畫、派工、退修、
範圍內 DBG-A 與完整骨架驗收。初始化專用細節只在選用時讀
[supervised-initialization.md](../../project-init/references/supervised-initialization.md)，共用分責、
候選不可信、續接與停止條件引用 [主代理程序](../../dev-workflow/references/supervisor-delegation.md)。
installed 使用端依實際安裝位置解析必要 sibling Skill；下游專案不需存在 ToukaDev source repo。

主代理只派工及驗收，執行者撰寫所有候選與整合。範圍內設定修正可依委託續行；技術棧
實質改變返回 INIT-A，需求、安全或驗收條件改變返回 INIT-B，必要時兩者重核。驗收結論為
初始化階段的 SUPERVISOR_ACCEPTANCE，不冒稱 dev 的 DEV-B 或嚴格獨立 reviewer qualification。
未選代審者沿原路線；brownfield 不使用本 greenfield 迴圈。

Debug 記來源流程與精確中斷點，修復後返回原步驟。已有且適用的驗證必跑；依順序尚待建立
者保留重現、原 FAIL、補齊步驟及責任，最終驗收前全部收斂。正常 TDD RED 不算失控，
第三次同方向失敗停止盲試、完成五維分析及 DBG-A；同問題預設兩輪自動修正／重分析，換 agent
或載體不清零。current 記初始化中／已完成及證據來源；檔案存在或自稱已核准不證明完成或授權。

品質以根 AGENTS shared block 為正本，四份投影完全同步。共通 SOLID 逐項按語言及範式說明
證據或不適用理由，不硬造 class、繼承、interface 或 Registry；Python 型別／頂層匯入義務保留，
React 保留元件分責與領域 Custom Hooks，其他 UI 依框架採合適資料存取抽象。
spec 記核准品質與初始化驗收條件；專案 AGENTS「技術棧與執行命令」引用既有工具配置，
作為實際命令正本。quick schema v1 與已宣告 validators 不變，語言分層不能跳過必要守衛。

現有工具流程限 Python／JS／TS；其他語言揭露模板、測試、lint、型別與安全掃描缺口，
補齊專案必要驗證前不承諾自主完成。最小骨架測試依可執行能力提供成功與失敗觀察，不為
湊測試新增業務功能；空測試、本地設定、遠端 CI 及部署分開記錄。

## 影響與限制

保留 ADR-030 的按需路由，F2／F17 同步封閉程序及必要義務；F6 除同步外驗證獨立核准的
有限品質 corpus，包含四份同步弱化仍拒絕的情境。文字契約、lint 與測試不證明 agent 必然
遵守流程，也不證明任意程式完整符合 SOLID；真實 source 試行與 installed Skill 試行另列。

步驟 13 逐項核對 Git 授權，可交付骨架已驗收但未提交；步驟 14 不從初始化完成推定後續
功能、projection、push、部署或外傳。strict／CODEX_NATIVE、F10 schema、F13–F16、既有安全
守衛演算法與專案禁令不變。本案不新增引擎、背景排程、持久授權服務或安裝器。

## 驗證及回復

原始 RED／GREEN、完整回歸、有限 corpus 與行為試行的分層結果由
[實作證據](../evidence/initialization-supervision-quality.md) 記錄，未執行者標 NOT RUN。
本 ADR 只保存決策及當次核准來源，不取代原始人類委託或主代理驗收。

回復先停止選用新路線並保留候選、current 及原 FAIL；若需回復 source，以完整核准變更組
同步處理入口、程序、模板、共同基線、路由與測試。已生成專案不自動重建或覆寫；Git、
installed bytes 及下游資料操作各依實際授權辦理。
