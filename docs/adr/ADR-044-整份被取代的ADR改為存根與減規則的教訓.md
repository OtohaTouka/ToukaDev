# ADR-044：整份被取代的 ADR 改為存根與減規則的教訓

- 日期：2026-10-15
- 狀態：已接受（人類核准的一頁計畫中，改 ToukaDev 的第 7、8、9 項逐項核准；修訂 ADR-033 D6 單獨核准；主代理代審）
- 修訂：ADR-033 D6（決策 6「既有 ADR 內文不改寫」：整份被取代的 ADR 可以換成存根，全文留在 git）
- 影響範圍：`docs/adr/` 的 22 份存根、10 份檔首現況行與索引；improvement-loop 的 improvement-run；HANDOVER。
  常駐載入的規則（四份共同區塊、各 SKILL.md）、守衛與測試都沒動

## 背景

這是一次跨兩個專案的規則減負任務。改 ToukaDev 的部分照改進任務處理（逐項核准、整個 repo 的停止線），來源是減負分析，
不是流程問題紀錄。

- ADR 目錄 43 份（374,172 B）中，22 份整份被取代（162,801 B、2,371 行）：21 份是 ADR-033 退役的 Codex 審核機制，1 份是
  ADR-011（framework runtime 部分由 ADR-015、其餘由 ADR-039 取代）。規則、守衛、測試、SKILL 與 references、glossary、
  HANDOVER 都沒有引用它們，只有其他 ADR 互引與索引列。
- 這些檔的狀態行多半還寫「已接受」，因為 ADR-033 D6 規定既有 ADR 內文不改寫；直接打開檔案會以為仍有效。另有 10 份部分
  被後來的 ADR 推翻，只有索引的狀態欄寫了，檔內沒寫。
- ADR-033 D6 的源頭：刪除交班、證據與提案資料夾時，選擇不回頭改 ADR 裡指向已刪檔案的連結；2026-10-09 隨 ToukaDev PR #2
  合併，狀態行記 DEV-A 由人類核准。當時的人類原話沒有留在 git 或本機紀錄，找不到。

## 教訓

- 減規則時保留每個要求，把條文縮成一行索引、或只把理由與歷史搬走，實寫量過後省得很少，縮成索引還多出兩處要維護；能省的
  主要是重複內容與非規則內容（例如整份被取代的歷史文件）。
- 只憑估計提出的減量，實寫後被推翻。提議前先照「保留每個要求」實寫一部分、量過，就不必重走估了又推翻的試錯（D4）。

## 決定

1. **D1 修訂 ADR-033 D6**（人類單獨核准）：整份被取代的 ADR 可以換成存根，全文留在 git。只限整份被取代的；部分被推翻或
   仍有效的 ADR 內文照舊不改寫（D3 只在檔首加一行）；指向已刪檔案的連結仍以 git 歷史為準。
2. **D2 存根格式**（第 7 項）：保留原檔名與編號，索引連結與其他 ADR 的互引都不斷。內容約 8 行：
   - 標題行照原檔；
   - 日期：原日期；
   - 狀態：已歸檔，寫明由哪份 ADR 取代；
   - 現在：一句話說明它的決定現在落在哪（取代它的 ADR，或已移除的機制）；
   - 原檔記載的關聯：原檔狀態行與檔首寫的修訂、取代、補充、擴充或延續，每個編號都帶 `ADR-` 前綴；沒有就不寫；
   - 全文：`git show <commit>:docs/adr/<原檔名>`，commit 用換成存根前最後一個含全文的版本。

   索引的狀態欄改成「已歸檔（…）」，連結不變。這次換的是 005～014、016～018、020～028，全文的 commit 是 `6888149`。
3. **D3 部分被推翻的 10 份加一行現況**（第 7 項）：002、003、004、019、029、030、031、037、040、042 的標題下加一行
   「現況：…」，寫哪一部分被哪份 ADR 推翻、取代或修訂，和索引狀態欄一致；原文其他字不改。
4. **D4 減法先實寫量過**（第 8 項）：improvement-run「分析」第 4 點「另列減法」加一句：「減規則時保留每個要求；提議前先照
   這個原則實寫一部分、量過能省多少，不只憑估計。」
5. **D5 交班待辦結案**（第 9 項）：「另一個專案檢查 ADR 編號的守衛有沒有略過 `.toukadev`」已確認有略過（排除清單含它，
   且有測試），從 HANDOVER「下一步」移除。

## 不採用

- 把「搬移不算弱化」寫成定義：實寫量過後搬移與瘦身都省得很少，不值得放寬受保護的規則。
- 把減法擴到下游專案：會碰 improvement-run「來源」只讀其他專案 `.toukadev/lessons/` 的鎖定句；各專案在自己的任務做，
  D4 提供做法。
- 用規則檔大小當觸發：做成提醒要改記錄程序的鎖定句；做成守衛的理由只和單一工具的讀取上限有關，這次不處理。

## 後果

- 修訂 ADR-033 D6：整份被取代的 ADR 可以換成存根，全文留在 git。
- 22 份的全文只在 git 歷史，看原文用存根上的 `git show` 命令；搜尋 ADR 目錄時不再出現它們的內文。
- 已知限制：存根的「現在」一句是摘要，細節以原文為準；沒有守衛檢查存根格式與索引一致，靠審核；以後再有整份被取代的 ADR，
  要不要換成存根由當次任務決定，不會自動換。
- improvement-run 的新句要重新安裝 Skills 才生效；一頁計畫已同意合併後重裝。
